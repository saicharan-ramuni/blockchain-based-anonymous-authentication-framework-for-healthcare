10 Algorithms — Healthcare EHR Scheme

Algorithm 1
System Setup

HA generates CLA-split keys: P_pub, P_pub1, P_pub2 and doctor decrypt key y.

Algorithm 2
Registration

Patient/Doctor computes α_i = H₁(DOB, SA, OD). No biometric hardware needed.

Algorithm 3
Partial Key Extraction

HA issues pseudonym ID_i = Enc(RID ‖ Role) and partial private key psk_i.

Algorithm 4
Key Generation

Precomputes SID/KID sets and encryption set Q/ek. Zero EC multiply on signing.

Algorithm 5
Multi-Factor Login

Password + DOB + Security Answer. Recovers psk_i = A_i · UPW⁻¹, verifies B_i.

Algorithm 6
EHR Sign & Encrypt

c_i = m_i ⊕ ek_k. σ_i = psk + h₂·SID + h₃·x. ZERO EC multiplications!

Algorithm 7
Verify & Decrypt

Node verifies σ_i·G = gpk + h₁·Ppub + h₂·KID + h₃·upk. Doctor decrypts m_i = c_i ⊕ H₁(y·Q_k).

Algorithm 8
Mutual Authentication

ECDH session key K_ab. Role-based access: only DOCTOR role can decrypt EHR.

Algorithms 9 & 10
Revocation & Evidence

Chameleon Hash: CH_i = (ζ·ck + H₁(j,cred,HK))·G. HA updates evidence without changing block hash.
