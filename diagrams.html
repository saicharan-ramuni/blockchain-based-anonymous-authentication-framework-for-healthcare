Dual-Mode Architecture Diagram

Mode A — Lightweight (Off-Chain): Fast peer-to-peer mutual authentication for routine telemedicine; no blockchain overhead; SQLite local storage.
Mode B — Blockchain-Anchored (On-Chain): Immutable EHR upload, cross-hospital audit, Chameleon Hash evidence correction via Ganache smart contract.

Fig. 4

Dual-Chain Blockchain Structure

Historical Verification Chain (HVC): Append-only, immutable. Every verified EHR upload is recorded permanently for HIPAA/GDPR audit compliance.
Evidence Revocation Chain (ERC): Uses Chameleon Hash — the Hospital Authority can modify evidence content using the trapdoor key ck without creating a new block or invalidating subsequent entries.

SID/KID Precomputation Concept — Zero EC Multiplication at Signing

The key innovation enabling IoT feasibility. All expensive EC scalar multiplications (T_Mu ≈ 97 ms on ARM Cortex-A72) are shifted to a one-time offline phase. At signing time, the device only performs 2 SHA-256 hash calls + 6 modular multiplications (≈ 8.4 ms total), replacing the conventional random-nonce generation T = t·P.
